Have/install 
  Node.js: https://nodejs.org/
  MongoDB: https://www.mongodb.com/try/download/community
  MongoDB Compass: https://www.mongodb.com/products/compass

1. open terminal to this directory
2. npm install
3. make sure MongoDB is running.
4. in Compass create database Users, then create and import collections:
  Users.json as users
  Accounts.json as accounts
  Transactions.json as transactions
5. run node server.js
6. open http://localhost:8080 in browser

Find log in details in Users.json
